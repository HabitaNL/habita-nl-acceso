Después de obtener el UID

Desde la cuenta que administra Firebase, abre Authentication → Usuarios y verifica que el usuario corresponda al Gmail elegido. Luego, en Firestore → Datos, crea manualmente el documento users/UID con los campos email, role = admin y status = active.

Por seguridad, no cambies todavía las reglas de Firestore. El gestor compartido solo funcionará después de publicar reglas revisadas.

La aplicación debe abrirse desde un dominio HTTPS autorizado en Firebase Authentication. Abrir index.html con doble clic no permite iniciar sesión.
